# Sage security hardening — October 20, 2026

Status: proposed branch changes; production not modified.

## Implemented
- Refreshed dependency lockfile, upgraded Vite to 6.4.4 and React Router DOM to 7.18.4, and classified the Tailwind typography plugin as a build-only dependency. npm audit originally flagged 23 packages (1 critical, 13 high, 8 moderate, 1 low). Runtime audit now reports zero. Full dependency audit still reports 8 build-tool packages (5 high, 3 moderate) in the Tailwind 3/braces/selector-parser chain. These alerts are NOT fixed by excluding dev dependencies from the runtime audit. A Tailwind 4 migration needs separate layout verification rather than a forced audit upgrade in this security patch.
- AI/email routes now require exact production or this deployment's VERCEL_URL/VERCEL_BRANCH_URL origins. Unrelated *.vercel.app origins and missing origins are rejected. Local development origins are allowed only outside NODE_ENV=production. Origin is not authentication and can be forged by non-browser clients.
- JSON parsing counts actual streamed UTF-8 bytes before parsing, including when Content-Length is omitted or false. Enforces JSON object shape and content type. Limits: chat 20 KB, trip plan 10 KB, email 18 KB.
- Instance-local throttles cap and expire their maps, fail closed when full, and avoid unbounded growth. Email also limits a recipient to two attempts per ten minutes per instance; failed delivery attempts count too. These are not distributed limits.
- AI generation uses a 25-second client timeout, 2,048 chat / 4,096 trip-plan output-token caps, and disables Gemini thinking budget to keep work bounded. Provider billing budgets/quotas still need verification.
- Email subject is composed by the server; plan URLs must point to known Sage planner routes on trusted origins with no URL credentials. HTML remains escaped. Resend requests have a ten-second timeout; errors do not log message bodies.
- Added pinned, least-privilege CodeQL and CI workflows, weekly Dependabot checks, security headers and credential-file ignore rules. Runtime audit gates CI; the eight remaining build-tool alerts are explicitly tracked here.
